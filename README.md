# PixelPet — пиксельный питомец для Windows

Питомец ходит по рабочему столу, бегает, машет рукой и поднимает руки
с надписью «о май гад». Через 1,5 секунды надпись начинает исчезать;
плавное исчезновение занимает ещё 0,5 секунды.

[Скачать готовое приложение для Windows](./PixelPet-Windows.zip)

## Запуск

Скачайте репозиторий через **Code → Download ZIP**, распакуйте его
и запустите `PixelPet.exe`. Файлы `sprites.png` и `walk.png` должны
лежать рядом с приложением.

Требуется Windows с .NET Framework 4 или новее. Python не нужен.
Приложение работает локально, не использует сеть и не добавляет автозапуск.

## Управление

- Левый щелчок: приветствие.
- Зажатая левая кнопка: перетаскивание.
- Правый щелчок: ходьба, бег, «о май гад», пауза, размер и выход.
- Меню также доступно через значок в области уведомлений.

## Сборка из исходного кода

Закройте питомца перед сборкой. В PowerShell из папки проекта выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт использует встроенный компилятор .NET Framework и создаёт
`PixelPet.exe` рядом со спрайтами. Дополнительные пакеты не нужны.

## Файлы

| Файл | Назначение |
| --- | --- |
| `PixelPet.exe` | Готовое приложение |
| `Pet.cs` | Исходный код C# и отрисовка с прозрачностью |
| `sprites.png` | Исходные кадры ожидания, бега и взаимодействия |
| `walk.png` | Отдельные восемь кадров ходьбы: 4 колонки × 2 строки |
| `build.ps1` | Сборка приложения |

Программа выравнивает кадры ходьбы по голове и линии земли.
Перемещение обновляется независимо от смены кадров.
Для движения влево спрайты отражаются. При запуске создаются
`sprites-transparent.png` и `walk-transparent.png`; это служебные файлы.

## Загрузка на GitHub

1. Создайте пустой репозиторий на GitHub.
2. Выберите **uploading an existing file** или **Add file → Upload files**.
3. Перетащите содержимое этой папки, включая `Pet.cs`.
4. Нажмите **Commit changes**.

Или загрузите через Git из этой папки:

```powershell
git init
git add .
git commit -m "Add PixelPet desktop companion"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Замените имя пользователя и репозитория в адресе на свои.
Спрайты созданы по пользовательскому фото с помощью imagegen.
